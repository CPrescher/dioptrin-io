# FabIO reading coverage target

Reference: [FabIO 2026.6.0, tag v2026.06](https://github.com/silx-kit/fabio/tree/9ddb6f6ce22e79056bec0f6e6b97d7ebc29cbece), commit `9ddb6f6ce22e79056bec0f6e6b97d7ebc29cbece`. The pinned registry has 36 entries and 35 unique codecs; ADSC aliases d*TREK. This inventory retains **every reader**, including raw input and masks. It is a target inventory, not a parity claim.

Outer gzip/bzip2 wrappers, content autodetection and neighboring-file series are separate coverage targets and remain pending. A TIFF-based detector is not marked supported merely because a generic TIFF can be decoded. Likewise, explicit HDF5 dataset reading does not establish Eiger-master/LImA/Lambda/sparse reconstruction parity.

The pinned PNM reader explicitly rejects P3/P4/P6/P7, and its Oxford TY5 branch is marked known broken. Those require independent evidence before treating them as working reference implementations. Sparse reconstructions and R-AXIS dynamic-range encoding also need explicit data/interpretation contracts.

Next expansion: close CBF/EDF header and wrapper gaps; add HDF5 master/source manifests and signed/float samples; then work through the remaining rows with small independent licensed fixtures. No PhaseSmith migration or Dioptas changes are part of this branch.
