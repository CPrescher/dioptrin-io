The pinned registry has 36 entries and 35 unique codecs; ADSC aliases d*TREK. This inventory retains **every reader**, including raw input and masks. It is a target inventory, not a parity claim.

Outer gzip/bzip2 wrappers are supported by the optional wrapped::Reader for implemented native/container/legacy/image backends when their features are compiled. Content autodetection, HDF5 wrappers and neighboring-file series remain separate pending targets. A TIFF-based detector is not marked supported merely because a generic TIFF can be decoded. Likewise, explicit HDF5 dataset reading alone does not establish Eiger-master/LImA/Lambda/sparse reconstruction parity.

The pinned PNM reader explicitly rejects P3/P4/P6/P7; its P1/P2 loops do not advance the row index, which is recorded as a reference behavior difference, and its Oxford TY5 branch is marked known broken. Those require independent evidence before treating them as working reference implementations. Sparse reconstructions and R-AXIS dynamic-range encoding also need explicit data/interpretation contracts.

Continue through every remaining row, using the pinned upstream codec suite and its exact files as an acceptance corpus (see FABIO_PARITY.md). CBF/EDF semantic/external headers, HDF5 typed/master sources, remaining codecs, full metadata comparisons and discovery all remain part of the target. No PhaseSmith migration or Dioptas changes are part of this branch.
