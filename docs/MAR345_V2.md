# MAR345 / MAR555 original V2 and explicit eight-bit compatibility

The optional `mar345` reader supports the original J. P. Abrahams PCK V2
encoding. Its default follows the unchanged original writer and reader, not
FabIO's incompatible older eight-bit C implementation. Both use the same V2
marker text, so the marker cannot distinguish their block grammars. There is
no failed-read retry, heuristic dialect detection or binary whitespace trimming.

`Reader::open(path, Limits)` selects the original dialect. The additive API is:

```rust
mar345::Reader::open_with_options(path, limits, mar345::Options {
    v2_dialect: mar345::PckV2Dialect::FabioLegacyEightBit,
})
```

`PckV2Dialect::Original` is the default. `Metadata::pck_version` preserves one
or two, and `pck_v2_dialect` records `Some(Original)` or
`Some(FabioLegacyEightBit)` for V2; V1 has `None`. The explicit eight-bit option
selects that block framing with the original signed16 source predictor. It does
not reproduce the older decoder's unsigned-division arithmetic error.

The existing `Reader`, `FrameBuffer`, immutable-source behavior and U32 output
remain intact. The [reader overview](MAR345_READER.md) includes the expanded
contract. Historical proof reports remain unchanged; the new
[scoped proof](mar345/2026-11-06-marv2-vds-ojpeg.json) separates the original and
compatibility profiles.

## Independently established format facts

| Encoding | Header fields, low bits first | Run length | Signed residual widths |
| --- | --- | --- | --- |
| V1 | 3-bit run exponent, 3-bit selector | 1–128 | 0, 4, 5, 6, 7, 8, 16, 32 |
| Original V2, default | 3-bit run exponent, 4-bit selector | 1–128 | 0, 3 through 16, 32 |
| Explicit FabIO legacy framing | 4-bit run exponent, 4-bit selector | 1–32768 | 0, 4 through 16, 32 |

All sixteen original V2 selectors are valid, including selector fifteen for
32-bit residuals. In the incompatible eight-bit form, selector fifteen is
unassigned and rejected. The existing bounded MIT-derived bit reader,
signed-residual extraction, modulo16 reconstruction and predictor are reused;
only factual block parameters differ. No LGPL implementation or decoder
expression is translated into native code.

The decisive primary source is the original JPA `pack_c.c`, distributed in the
[official CCP4 8.0.0 source archive](https://ftp.ccp4.ac.uk/opensource/libccp4-8.0.0.tar.gz).
Its `v2pack_wordimage_c` emits the exact MAR V2 identifier, calls signed-short
`diff_words`, then `v2pack_chunk`, which writes three run bits and four selector
bits. Its `v2unpack_word` reads that seven-bit grammar and uses signed-short
neighbor arithmetic. The original encoder and decoder roundtrip authored U16
bit patterns above 32767 exactly. This independently establishes both framing
and signed predictor semantics; the generated native fixtures alone do not
serve as evidence for the format definition.

The archive SHA256 is
`cb813ae86612a0866329deab7cee96eac573d81be5b240341d40f9ad5322ff2d`;
original C and header hashes are
`90c61546fd44f6d56ca8d75806cfa4da86ff6f27aed911aeae56a2276dd7bcbb`
and `a2ab66320c27637cc44599fd9f10630f31b44833d3a62b2e9a17246f4491dab6`.
An independently retrieved Debian libccp4 6.5.1 copy corroborates these semantics.
The [CBFlib manual](https://cbflib.sourceforge.net/doc/CBFlib.html#3.3.2) also
describes the seven-bit alphabet, but its modified row/section predictor is not
used as the MAR oracle. The manufacturer's
[MAR layout manual](https://marxperts.com/man/html/mar345_formats.html) establishes
the surrounding header, U16 base image and unsigned high-count table.

## Source counts, bounds and snapshots

Original headers, all sixteen binary words, repeated source text entries,
marker delimiters, endianness, overflow records and padded or compact table
bytes remain metadata. Source U16 words widen exactly to U32; high-count values
such as `2^31` and `2^32 - 1` remain exact original unsigned words. Signed16
predictor arithmetic preserves the source's U16 bit representation. Stored row
order is retained, with no flip, calibration, masking or normalization.

Each complete block and field must fit its declared output and encoded window.
The stream must end at the final used byte with zero unused bits. Truncation,
block overruns, unexplained tails, nonzero unused bits and unsupported selectors
invalidate the output. A selected dialect is never retried as another one.
Some all-zero streams can be valid under both grammars; the recorded caller
policy remains authoritative rather than a claim of automatic identification.

Full U32 output and encoded-window byte limits apply before payload allocation;
headers and overflow tables retain their metadata budgets. Existing immutable
path/open-handle checks detect ordinary mutation or replacement around indexing
and reads. Every failed read hides pixels and shape, including reused output.
There is no shared decoded cache. Explicit stream capture and gzip wrapping use
existing APIs and continue checking the encoded original after staging.

## Independent validation and licensing boundaries

The proof validates three distinct sources of evidence:

- Thirty-two independent CC0 original-dialect fixtures cover all sixteen
  selectors and eight run exponents, both byte orders, high tables, CRLF,
  signed neighborhoods, reserved values and signed32 residual boundaries.
  Every source word and metadata field matches native output, and the unchanged
  original JPA V2 decoder matches every authored word.
- Five separate, unchanged original writer/reader roundtrips encode authored
  U16 arrays: signed neighborhoods, unsigned first rows, reserved words,
  positive data and varied values. Native reads the actual original encoder's
  complete output, including its terminal padding, and matches every word.
- Thirty-nine explicitly selected eight-bit fixtures retain separate evidence.
  Native matches their authored words and metadata. FabIO's separate C8 oracle
  matches 37 exactly. Two cases expose its unsigned neighbor accumulation and
  division, producing different words for negative sums with a remainder.
  The independently verified original signed predictor and a complete
  arithmetic accounting qualify those differences; they are not attributed to
  the original seven-bit decoder, which matches all original-profile cases.

The pinned default FabIO path recognizes V2 markers but still invokes its
V1-only `unpack_pck`. It is kept unchanged. For original-profile fixtures, ten
all-zero subsets match coincidentally, eight safe calls return wrong counts,
and fourteen unsafe V1 reinterpretations are not called. For the explicitly
selected eight-bit fixtures, fourteen zero subsets match, five return wrong
counts, two big-endian sources fail format identification, and eighteen unsafe
interpretations are not called. These groups are separate. Coincidental zero
matches are not proof that FabIO's default implements either V2 grammar.

Unsafe external reference calls require independent source/table/block/tail
admission: at most 1 MiB input and 32768 output words. Separate child processes
have CPU, wall-time, file-output and core limits. C wrappers attempt an
address-space limit after execution and record the operating-system result;
output guard words must remain unchanged. The legacy C8 wrapper has one input
prefetch sentinel, which admission ensures never supplies a source field.
Unrelated reference failures, changed inputs, guard failures and unexplained
word differences fail the proof rather than becoming qualified format defects.

Original CCP4 modified-LGPL3/UK-law code and pinned FabIO LGPL C code are compiled
unchanged outside Git as test-only executables. Source/archive/compiler and
executable hashes are recorded; temporary binaries are removed after the run.
No LGPL source or decoder is vendored, linked into the product or used at
runtime. Existing MIT attribution remains in
`licenses/native-readers/FabIO-MAR345-MIT.txt`. Fixture data and independent
packing generators are CC0.

The two actual pinned corpus files remain V1 and still match unchanged FabIO:
`example.mar2300` and `Fe3O4_023_101.mar2560`. No acquired detector V2 sample was
found. Original-writer output establishes a real independent producer contract,
not acquired-detector V2 coverage. Raw spiral/old IMAGE storage and predictor
dimensions below two remain explicit unsupported layouts.

Eleven targeted Rust tests pass, including wrong-dialect rejection, malformed
blocks/tails, resource bounds, source replacement, explicit eight-bit and default
original nonseekable captures, outer gzip and stale-output invalidation. Strict
scoped Clippy and eleven Python admission/provenance/classification controls
pass. The root owns the final full-feature and isolated-feature matrix.

## Reproduction

Generate the small fixtures with
[the original-profile generator](../scripts/generate_mar345_original_v2_fixtures.py)
and [the explicit eight-bit generator](../scripts/generate_mar345_v2_fixtures.py).
The external directory below contains the exact official archive plus its
unmodified `pack_c.c` and `pack_c.h`; the helper verifies all three against the
pinned hashes and verifies source-file identity against archive members.

```sh
/tmp/dioptrin-io-fabio-suite-env/bin/python scripts/mar345_v2_reference.py \
  --probe target/release/examples/api_probe \
  --fabio-source /tmp/dioptrin-io-fabio-2026.6.0 \
  --ccp4-source /tmp/dioptrin-io-ccp4-8.0.0 \
  --corpus /tmp/dioptrin-io-fabio-corpus \
  --report docs/mar345/2026-11-06-marv2-vds-ojpeg.json
```
