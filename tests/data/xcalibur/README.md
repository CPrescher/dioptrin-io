`records.ccd` is an independent CC0 fixture generated by
`scripts/generate_xcalibur_fixtures.py` using explicit little-endian struct
packing. It includes all record families, reserved polygon coordinates,
nontrivial treatment/replacement fields, unequal binned row/column counts,
UTF-8 text and an opaque trailer. It contains no experimental detector data.
The layout is documented by MIT FabIO 2026.6.0 xcaliburimage.py; its attribution
is retained under licenses/native-readers/FabIO-Xcalibur-MIT.txt.
